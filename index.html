⌨️ Cómo activar el teclado chino

Activa el teclado Pinyin del dispositivo para escribir caracteres chinos directamente.

Windows 10 / 11

Configuración → Hora e idioma → Idioma y región → Agregar un idioma → Chino (simplificado). Cambia de teclado con Windows + Espacio.

macOS

Ajustes del Sistema → Teclado → Fuentes de entrada → Añadir Chino simplificado - Pinyin. El atajo de cambio depende de la configuración del teclado.

iPhone / iPad

Ajustes → General → Teclado → Teclados → Añadir nuevo teclado → Chino simplificado (Pinyin).
